# SVG assets

All five SVGs are self-contained and use inline data URIs for the supplied RGBA portrait assets and fonts. They make no network requests. The GitHub social marks are inline vector paths/text rather than remote icon fonts. Official profile links are provided as clickable Markdown links in the root README because links inside SVG images are not clickable on GitHub.

- `hero.svg`: greeting, name, role cycle, pitch, portrait, Pune / SPPU.
- `about-life.svg`: capabilities and three-slide interests carousel (12-second full cycle; each slide lasts about 4 seconds).
- `stack.svg`: technology orbits and labelled chips.
- `id-dashboard.svg`: hanging ID badge, barcode, portrait and light sweep.
- `connect.svg`: supplied right-pointing portrait and social cards.
- `FONT-LICENSES.txt`: font source/license notes.
